# Cumulative ownership through playback and news

Ticket #74 extends the cumulative path introduced in #72 and #73. Its new tests live in `test_cumulative_races.py`, `test_cumulative_input.py` and `test_jev_cumulative.py`. The existing legacy admission/race tests still run, but their results do not substitute for the new cumulative cases.

An observed period participates in capture, quiet and Announcement eligibility. Natural Follow-up expiry can change the acoustic state to idle while its already observed thought remains captured. Queued news waits for that thought to settle. Delayed first delivery uses the original source onset and bounded reply history: an eligible source can arrive after Follow-up expiry; a source starting after the window cannot gain that old authority. A period begun while thinking keeps that phase and its source identity across first reply audio. An old farewell cannot retire a newer observed correction.

Applying a floor decision no longer blocks the event driver on SDK interruption. A ready revision records its Hub scope hold synchronously before awaiting the stop. Capture continues processing newer source revisions while the stop waits. If the observed thought changes, the obsolete prepared line is not submitted. The next ready decision receives a higher revision, built from the original request plus the current exact source history, so words are not appended twice. Typed replacement and shutdown retire the old epoch; late results have no output authority. Floor-only speech still creates no scope hold and chooses or cancels no Task.

Announcements follow the same independent floor/readiness policy with no invented User request. A voice-only stop replaces the active Announcement lease with a finite contextual Follow-up window. It cannot leave the old infinity expiry behind. A queued second update remains distinct and is delivered once after the correction finishes. Quiet-mode bundles already delivered are not replayed after a stop. Played text is refreshed from the current output estimate for each active assessment and remains labelled `queue_estimate`, not physical hearing.

Mixed-source admission uses exact observed word boundaries. Jev receives one Choice question per currently eligible word, alongside the independent floor and readiness questions, all against the same snapshot. The adapter groups consecutive directed words into source/revision/character ranges. The Hub validates those ranges against observed word boundaries and rejects foreign revisions, inside-word offsets and overlapping selections. It constructs accepted segments by slicing the authoritative transcript. The classifier never supplies replacement command text. An uncertain word withholds readiness; a clearly directed floor decision can still stop output while the thought remains unfinished.

A confidently unrelated partial does not tombstone the future of its still-active recording. Its observed prefix loses admission authority, while bounded capture watches for an appended directed clause. Only newly appended words receive admission questions. Case and surrounding-punctuation changes reconcile against the retired word identities. If a revised hypothesis changes that prefix incompatibly, the source is rejected with a visible retry notice rather than guessing where background ends. A finalized unrelated source becomes a terminal tombstone. New cumulative tests exercise an early unrelated partial followed by “Jarvis, wait…” before endpoint, not just a final transcript containing mixed dialogue. These are mechanical provenance checks; inaccurate semantic classification can still miss speech and requires live measurement.

The old four-source/30-second bounds rejected a scripted 12-segment explanation before it finished. The development replay now retains all 12 segments, 38 words and 234 characters over 33 seconds of repeated three-second pauses, and submits them once. Normal period bounds are therefore 32 retained sources, 120 seconds and 320 assessments. The existing 6,000-character accepted-request limit remains; overflow is reported without silently truncating or admitting a tail. A failed observation has an additional 30-second ceiling and no silence-only retry storm. Active capture keeps its separately configured per-recording duration bound, which defaults to 30 seconds.

Provider work is bounded by 512 eligible-word questions plus floor/readiness, 24,000 JSON state characters and a 256 KiB response. At the word ceiling the HTTP fake exercises 514 questions in one request under 300,000 body bytes; the next word fails visibly before sending anything. These are client ceilings, not proof that every maximal request fits the provider's token limits or deadline. Usage records include the actual question count and returned token usage. Request limits, semantic accuracy and question fan-out latency/cost need the agreed bounded Jev trial. No paid calls ran here.

Rejected source identities remain bounded at 64 without eviction; saturation blocks unknown sources while known pending sources can finish. Duration-limited or aborted terminal events fence their own source even if onset delivery was missing. Empty final input retires without a classifier call and restores a bounded listening window. Capture replay verifies that resumed speech invalidates a prepared acoustic endpoint, updates the same source's hypothesis revision and delivers only the corrected final source.

All results above use fake agents, classifier/HTTP adapters, capture engines and clock. They establish ownership, capture scheduling and exact-word behavior. Real Jev decisions, repeated-batch STT accuracy/throughput, physical stop timing, wake recall and meaningful-response latency remain unqualified; #76 retains those gates. Recordings, real transcripts, credentials and provider credits were not accessed or used.
