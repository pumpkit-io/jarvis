# Complete-thought readiness

With `JARVIS_ADMISSION_BACKEND=jev`, initial listening now uses the same cumulative observations as resumed speech. A local acoustic endpoint supplies a corrected source transcript. It does not itself submit a Talker turn. An unfinished or uncertain semantic decision retains the opening while later observed sources and silence are reassessed. Complete-sounding sentences receive the same treatment as unfinished grammar. There is no universal three-second wait. Whole initial end controls such as “that's all” and “basta così” retain their existing silent local behavior; longer requests containing those words remain candidates.

Snapshots include the original source boundaries, within-source pauses, pauses between consecutive observed sources, currently active source identities, elapsed silence, current request/revision and preceding request text. Pause timing survives discarding unrelated words. Corrections replace the previous hypothesis for the same source. A ready partial cannot submit until a corrected final source exists and capture reports no active source. This uses final local STT as the stability boundary rather than declaring a changing partial authoritative.

Initial ready speech starts one Spoken request. Ready thinking-origin speech appends the exact accepted sources and synchronously holds the existing Hub Task scope before stopping the obsolete generation. It can do so without a playback floor label because no reply audio is playing. An unfinished floor decision still does not start a Talker turn or select Tasks. Directedness, floor-taking and readiness remain separate decisions.

The existing four-source, 6,000-character, 30-second and 80-assessment bounds remain. A listening thought that reaches a limit returns to idle with explicit recovery status; it is never submitted as a truncated request. Rejected source identities retain their fence until a fresh wake. Typed input retires an already observed cumulative thought and its pending result. The existing protection for raw initial capture whose onset has not yet reached VoiceMode remains intact.

The synthetic development intents are frozen in [cumulative-readiness.json](../../tests/fixtures/cumulative-readiness.json), SHA-256 `33693ddf712a292024e9476364fa63bbe0365a4488e859b6f99370f4876debf1`. The 16 continuation cases combine EN/IT, mid-sentence/complete-sounding openings and 0.5/1/2/3-second gaps. Their expected intent is unfinished during the gap and ready after the supplied continuation. Two controls are clearly finished EN/IT requests. These fixtures are visible development material, not untouched confirmation inputs.

The scripted Hub evaluation preserves all 16 openings and continuations with zero premature submissions and zero duplicate submissions. Both completed controls submit, with zero missed controls. They use an injected 500 ms final-transcript delay: `cumulative_readiness.end_wait_ms` is 500 ms and `readiness_wait_ms` is 0 ms with immediate scripted decisions. Meaningful audio remains a separate `speech.first_meaningful_audio_ms` measurement whose basis is `queue_estimate`; no physical meaningful-response latency was measured. Source correction, thinking continuation, retention expiry and typed replacement have separate regressions. These results establish the harness behavior when semantic decisions are supplied, not Jev's accuracy on the intents.

The cadence remains 400 ms. The controller adds no fixed completion delay after a ready corrected source. Local final transcription still depends on the existing endpoint policy: its ordinary acoustic endpoint waits about 500 ms, and Smart Turn's incomplete path can extend that to about two seconds. The fake capture tests cover those existing policies. Their interaction with actual Jev decisions, repeated batch STT throughput and meaningful response time needs the bounded live development trial before independent confirmation. A low-confidence result waits until more evidence or an explicit limit; the code cannot infer an unspoken continuation perfectly.

Real Jev semantic errors, premature commitments, missed completed requests and physical latency are all unmeasured here. The live meaningful-response targets remain p50 at most 1500 ms and p90 at most 2500 ms, measured together with recognition errors and all attempted/failed/missing cases. No component medians are subtracted, and no fake-clock result qualifies those targets. No real provider calls, audio devices or credits were used for this ticket.
