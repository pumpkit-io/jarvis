# Voice controls and Jev status

In an interactive voice terminal, press **Ctrl-G** to stop the spoken reply immediately, without Enter. The terminal keeps the request you are editing. Ctrl-C exits the Hub; Ctrl-D at an empty prompt ends input. The existing `› ` prompt and `[hub]` notices remain. Piped input retains its line protocol, and text-only mode retains its existing input path.

The maintained `prompt_toolkit` input adapter handles editing and key decoding. The Ctrl-G callback retires old voice ownership, drains playback synchronously and requests interruption of the captured spoken generation. The SDK acknowledges that request asynchronously. Requests for the same generation coalesce, and the next generation waits for that pending interrupt so it cannot land on a newer reply. Background Tasks are not cancelled or put on a spoken-scope hold. A finite contextual Follow-up window opens, and typed interaction remains available. No STT result or Jev response is needed for this control. An SDK interruption error produces a separate “generation stop was not confirmed” notice; old voice output and tools remain fenced.

Select the intended provider with `JARVIS_ADMISSION_BACKEND=jev` and set `TYPESAFE_API_KEY` in `.env` or the process environment. Restart after changing setup. The key is never printed or copied from another repo. Jev remains pinned to `jev-1.14.0`; no alternate cloud provider is selected automatically. The explicit older `claude` setting is labelled as the legacy endpoint-only path, with its configured model.

The terminal distinguishes disabled assessment, missing credentials, rejected credentials, configured but unverified access, a valid response, timeout, throttling, malformed data, unavailable service and local input limits. “Configured” checks no provider account access and spends no credits. Readiness becomes “responding” only after a response passes the pinned-model, label, probability and usage checks. That does not qualify live recognition accuracy. An unavailable or unknown observation preserves playback; Ctrl-G remains local. Such an observation is a failed assessment, not a successful ignore or stop. A directed-stop trial must count its failed/missing result, not hide it among negative cases.

Opting into Jev sends bounded candidate text, including potentially unrelated speech, pause timing and recent conversation context to TypeSafe. Raw microphone audio remains local. Provider notices and usage metrics contain model/status, opaque source ownership and usage counters rather than candidate text, response bodies or keys. Existing local conversation records retain their own behavior. The existing audio-clip setting is separate and remains opt-in under gitignored `.jarvis/clips/`.

There is one provider request in flight, latest-snapshot coalescing and no automatic HTTP retry. Current deadlines are 700 ms for HTTP, 750 ms for the adapter and 800 ms for the voice controller. A normal talking period allows at most 320 assessments over 120 seconds, with 32 retained sources and 6,000 accepted request characters; failed observation retention also has a 30-second ceiling. Provider payload limits remain 512 eligible word questions plus floor/readiness, 24,000 JSON state characters and 256 KiB returned data. Limits are visible and do not silently truncate a request. No conversational requests run while idle, and silence-only retries stop after a failed observation. See [cumulative ownership](cumulative-ownership-races.md) for exact source retirement behavior.

Usage is accumulated across successful and failed requests. The terminal prints totals on the first request, failures, recovery, every ten requests and shutdown, without a line for every successful snapshot. Metrics record per-request question counts and cumulative reported input/output tokens. Missing usage is counted explicitly; a timeout is not treated as zero billed tokens. A successful wire response is not a measured semantic success. Runtime period ceilings bound work but are not a User-approved evaluation budget: repeated User requests can use more credits. Before an agent-run paid trial, agree its call/token/credit cap, retries/concurrency and recording conditions.

Fake terminal tests exercise Ctrl-G before Enter, buffer preservation, normal editing, Unicode and piped input. The fake-clock Hub regression keeps Jev blocked with no final STT input, drains audio without advancing the clock, permits an independent Task report and a silent typed reply, then rejects the obsolete classifier result. Fake HTTP tests distinguish timeout/throttling/malformed responses, recovery and unknown usage without exposing synthetic private fields. These checks do not qualify physical keyboard-to-silence timing, real provider availability, question fan-out cost or recognition accuracy. No real provider calls, audio devices or credentials were used for this implementation.
