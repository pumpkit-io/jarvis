# Allow opt-in cloud assessment of candidate speech

The User approved cloud admission on 2026-11-06 after local candidates failed the required targeting and latency gates. Candidate transcripts, including possible background speech, and bounded already-admitted request/reply context may be sent to the existing subscription solely for classification; raw audio stays local. This explicitly revises ADR 0014's pending cloud decision and ADR 0016's local-only admission wording. The default remains off, and implementation does not enable or edit anyone's environment.

The classifier has no tools, Task authority, Approval authority or conversational reply. It returns one floor/stop/ignore/uncertain label per original segment; the Hub receives only selected complete raw segments while retaining its already-admitted opening. A voice-only stop stops generation/audio without canceling Tasks. ADR 0016's ownership, scope holds and producer fences remain in force. There is no automatic provider/model fallback, new paid API, API key or account. Codex fallback is authorized in principle but remains unavailable until its tool-free subscription route is established.

The User also approved bounded subscription/model tests, two read-only Org Tasks and publication of reviewed aggregate metrics/public synthetic fixtures. Personal transcripts, raw recordings and diagnostic logs remain local. Microphone/speaker tests remain off overnight; physical checks require the prepared human session. This source change was developed with fake providers and a fake CLI, not real inference. The prior cloud screen has 22 completed cases and two unknown failures, so it does not establish independent acceptance. Separate frozen semantic, availability, latency and physical gates remain open under #38/#39/#40/#26.
